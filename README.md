# ENote — Flutter

> النسخة المستهدفة بالتحسينات الحالية هي تطبيق **Flutter داخل `lib/`**. ملفات React ولقطات المتصفح في هذا المشروع مرجع منفصل وليست دليلًا على شكل أو أداء التطبيق الأصلي. راجع [تقرير تحسين Flutter](FLUTTER_UI_UX_AUDIT.md) للتغييرات وحدود التحقق وأوامر الاختبار.

تطبيق إنتاجية وتنظيم دراسي متكامل للطلاب باللغة العربية، مبني باستخدام إطار عمل **Flutter** بتقنية **Material 3** ومعمارية **Feature-First Clean Architecture**.

تمت ترقية هذا التطبيق وترحيله من المشروع الأولي المكتوب بـ React (`studyflow.tsx`) ليتحول إلى تطبيق جوال أصيل يعمل بكفاءة على نظامي **Android** و **iOS** والويب.

## 🏛️ البنية المعمارية (Architecture)

يعتمد التطبيق على معمارية مجزأة تركز على الميزات (**Feature-First Modular Architecture**) مع فصل كامل للطبقات:

```
lib/
├── main.dart                       # نقطة الإقلاع وتهيئة التطبيق والـ ProviderScope
├── core/                           # الركائز المشتركة عبر التطبيق بالكامل
│   ├── constants/                  # الألوان، التصنيفات، والثوابت العامة
│   ├── theme/                      # ثيم Material 3 (فاتح وداكن) وخط Cairo العربي
│   ├── router/                     # إعدادات التنقل عبر GoRouter والتحويل التلقائي
│   ├── utils/                      # منسقات التواريخ والأوقات ومؤقت بومودورو
│   └── widgets/                    # ويدجتس قابلة لإعادة الاستخدام (Cards, Buttons, Inputs, Dialogs)
├── data/                           # طبقة البيانات والنماذج ومستودع التخزين
│   ├── models/                     # نماذج البيانات المتوافقة مع بنية React الأصلية
│   └── repositories/               # واجهات المستودعات وتطبيق التخزين في الذاكرة المؤقتة
└── features/                       # مجلدات الميزات (Feature Modules)
    ├── shell/                      # الهيكل المشترك (AppBar, BottomNavigationBar, Drawer)
    ├── onboarding/                 # شاشة تهيئة الطالب والملف الشخصي
    ├── dashboard/                  # الشاشة الرئيسية والإحصائيات السريعة
    ├── planner/                    # المخطط اليومي وإدارة المهام
    ├── pomodoro/                   # مؤقت التركيز التفاعلي
    ├── homework/                   # إدارة ومتابعة الواجبات المدرسية
    ├── goals/                      # متابعة الأهداف ونسب الإنجاز
    ├── habits/                     # متتبع العادات الأسبوعي التفاعلي
    ├── notes/                      # تدوين الملاحظات وتصنيفها
    ├── statistics/                 # الرسوم البيانية وتوزيع أوقات المذاكرة
    ├── settings/                   # الإعدادات وتبديل المظهر وحذف البيانات
    └── common/                     # موفرو الحالة المشتركة (Riverpod Providers)
```

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Flutter SDK**: 3.x+ مع Dart 3
- **Design System**: Material 3 مع دعم أصيل لـ RTL واللغة العربية
- **State Management**: [flutter_riverpod](https://pub.dev/packages/flutter_riverpod)
- **Routing**: [go_router](https://pub.dev/packages/go_router) مع `ShellRoute` وحماية المسارات (Guards)
- **Local Database**: [drift](https://drift.simonbinder.eu/) مع SQLite لتخزين منظم ودائم دون اتصال (Offline-first)
- **Preferences**: [shared_preferences](https://pub.dev/packages/shared_preferences) لتفضيلات المستخدم وحفظ المظهر
- **Typography**: خط [Cairo](https://fonts.google.com/specimen/Cairo) عبر `google_fonts`
- **Localization**: `flutter_localizations` و `intl` لدعم التواريخ والتقويم العربي

## 💡 الأنظمة الذكية الجديدة (Smart Systems)

1. **لوحة التحكم التحليلية (Advanced Dashboard Analytics):**
   - مؤشرات الأداء الرئيسية الأربعة (ساعات الأسبوع، المهام المنجزة، الجلسات، العادات النشطة).
   - بطاقة تفاعلية لحالة الطالب ومستواه مع شريط نقاط الخبرة XP.
   - مخطط أعمدة بياني لمقارنة ساعات المذاكرة عبر أيام الأسبوع السبعة.
   - شريط توزيع المجهود والوقت المخصص لكل مادة دراسية.
   - قسم المواعيد النهائية العاجلة والتنبيهات المباشرة.

2. **مكتبة الملازم والكتب (Material & PDF Library):**
   - تنظيم الملازم والكتب داخل مجلدات مخصصة لكل مادة دراسية.
   - بطاقات إحصائية لإجمالي الملازم والكتب وعدد الصفحات المقروءة.
   - متابعة نسبة قراءة كل كتاب أو ملخص (الصفحات المقروءة / إجمالي الصفحات) وتحديثها بلمسة واحدة.
   - تصنيفات المرفقات: كتب، ملفات PDF، ملخصات، بنوك أسئلة وامتحانات، وملاحظات.

3. **نظام تنبيهات الأهداف الذكي (Goals Smart Notifier):**
   - مركز تنبيهات مخصص يحلل معدل إنجاز الطالب وموعد التسليم.
   - تنبيهات الخطر العاجلة (إذا كان متبقي 3 أيام ونسبة الإنجاز أقل من 75%).
   - تنبيهات التشجيع (عند بلوغ نسبة الإنجاز 80% فأكثر).
   - إشعارات التهنئة والانتهاء عند اكتمال الهدف بنسبة 100%.

4. **منبه البومودورو المتقدم (Pomodoro Smart Alarm):**
   - نظام تنبيه صوتي واهتزاز (Haptic Feedback) عالي الدقة عند انتهاء الجلسات أو فترات الراحة.
   - إمكانية تفعيل/تعطيل الصوت والاهتزاز من الواجهة مباشرة.
   - ميزة التمديد السريع (إضافة 5 دقائق إضافية لإنهاء النقطة الحالية بلمسة واحدة).
   - مكافأة نقاط خبرة تلقائية (+100 XP) عند إتمام جلسة التركيز.

5. **نظام المخطط اليومي الذكي (Daily Tasks Rollover & Eisenhower):**
   - كشف ونقل تلقائي للمهام المتأخرة غير المنجزة من الأيام السابقة (Smart Rollover).
   - تصنيف المهام حسب مصفوفة أيزنهاور (عاجل ومهم / مهم غير عاجل / مهام روتينية سريعة).
   - نصائح ذكية حسب مستوى الطاقة والتركيز المطلوب لكل مادة أو نشاط.
   - كسب نقاط خبرة (+50 XP) عند إنجاز أي مهمة.

6. **نظام المكافآت والألعاب (Rewards & Gamification):**
   - 5 رتب دراسية مميزة (مبتدئ شغوف 🌟، باحث مجتهد 🚀، متفوق واعد 🎯، عبقري ENote 💡، أسطورة دراسية 👑).
   - نظام متتبع سلاسل المذاكرة المتتالية (Streaks Tracker).
   - منظومة الشارات والجوائز التفاعلية مع شروط الإلغاء ونقاط XP مخصصة.

## 🧭 نمط التنقل (Navigation Pattern)

تم تحويل الشريط الجانبي في نسخة الويب إلى تجربة جوال أصيلة:
1. **شريط التنقل السفلي (Bottom Navigation Bar):** للوصول السريع إلى الأقسام الأربعة الأكثر استخداماً (الرئيسية، المخطط، بومودورو، الواجبات) وزر "المزيد".
2. **الدرج الجانبي التفاعلي (App Drawer):** يوفر وصولاً مباشراً لجميع الأقسام الـ 9 مع معلومات الطالب وثيم التطبيق.

## 🚀 تشغيل المشروع (Getting Started)

1. تأكد من تثبيت Flutter SDK في مسار النظام (PATH).
2. قم بتحميل الحزم:
   ```bash
   flutter pub get
   ```
3. فحص الكود:
   ```bash
   flutter analyze
   ```
4. تشغيل الاختبارات:
   ```bash
   flutter test
   ```
5. تشغيل التطبيق على الهاتف أو المحاكي:
   ```bash
   flutter run
   ```
